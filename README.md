Image to Sketch Converter

- Image is a picture or other representation of a person or thing
- Sketch is a rough drawing representing the chief features of an object
- Definitions according to image processing:
    - Image is a matrix of pixels
    - Sketch refers to a simplified representation or outline of an image

- Image can be converted to a sketch by reducing the level of detail to highlight important features
- Techniques include- 
    - Edge detection
    - Blurring/ smoothing
    - Converting to grayscale
